## Prerequisites
For non-Windows users, __Lua 5.3 or later__ is required to be installed on your system in order to build.

The binaries for the required assembler ___(Flamewing's Macroassembler AS Fork)___ is included in `build_tools`. 
If supported, the build script automatically runs the correct binaries for operating system and architecture.
